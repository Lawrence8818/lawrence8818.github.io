  - question: 什么时候开始付 progressive interest？
    answer: 从银行第一次放款给发展商之后的下一个月开始。也就是你自己的头期部分用完、发展商发出下一个工程阶段的账单之后。这可能是签约后几个月，也可能超过一年，要看项目当时的进度。

    answer: 不会。在建期间你付的只是“已放款部分”的利息，本金要等正式月供开始才会减少。有些银行允许你多还一点，或提早开始正式月供，有需要可以问。
  - question: 正式的月供什么时候开始？
    answer: 通常是贷款全部放完之后，大约在你拿到钥匙（vacant possession）的时候。确切的起算点各银行不同，请看你的贷款批准信（letter of offer）。
  - question: 发展商可以帮我付在建期间的利息吗？
    answer: 以前的 Developer Interest Bearing Scheme（DIBS），就是由发展商代付买家在建期间的贷款利息，从 2014 年起已经不被允许。如果有人向你提出听起来类似的安排，请问清楚具体是怎么操作的，并且要白纸黑字。
  - question: 如果漏付了一期 progressive interest 会怎样？
    answer: 和任何一期贷款漏付一样处理：会有迟付费用，也会留在你的信用记录里，影响你下一次申请贷款。因为金额会随着每次放款而改变，建议从第一天就设定自动扣账。

很多第一次买新盘的买家都会遇到这个意外：SPA 签了，贷款批了，以为在拿钥匙之前什么都不用付。结果几个月后，银行开始每个月扣一笔小数目，而且越扣越多。

这就是 progressive interest（在建期间利息）。它是正常的，不是隐藏收费。弄懂它怎么运作，你就能好好做预算。

## 为什么会有这笔钱

买现成的房子，银行一次过把钱付给卖家，你的正式月供也马上开始。

买在建的房子，法律不允许发展商一次过收足房价。发展商要随着工程进度，按照 SPA 里的付款表分阶段发账单；银行也按同样的阶段放款。

银行只就“实际已经放出去的金额”向你收利息。一开始放得少，利息就少；放得越多，利息越高。

## 放款阶段（Schedule H）

公寓、服务式住宅这类分层产业，使用标准的 Schedule H 买卖合约，SPA 的 Third Schedule 列明了各个阶段：

| 阶段 | 占房价 |
| --- | --- |
| 签署 SPA | 10% |
| 地面以下工程 | 10% |
| 单位的结构框架 | 15% |
| 墙身、门窗框 | 10% |
| 屋顶、电线、水管 | 10% |
| 内外墙批荡 | 10% |
| 排污工程 | 5% |
| 沟渠 | 2.5% |
| 道路 | 2.5% |
| 交屋（vacant possession） | 17.5% |
| 交付分层地契 | 2.5% |
| 由律师以 stakeholder 身份保管 | 5% |

有个别地契的有地房屋使用 Schedule G，原理和分阶段的方式相近，但确切的百分比和顺序，请以你自己那份 SPA 的 Third Schedule 为准。

发展商交屋的期限，Schedule H 最长 36 个月，Schedule G 最长 24 个月，所以这些阶段会分布在这段时间里，而且间隔并不平均。

## 一个完整算例

假设一间 RM500,000 的公寓，贷款 90% 即 RM450,000，利率以 4% 作说明。你付的 10% 用来支付签约阶段，之后才轮到银行放款。

每月利息 = 已放款金额 × 4% ÷ 12。

| 这个阶段放款之后 | 银行累计放款 | 每月利息 |
| --- | --- | --- |
| 地面以下工程（10%） | RM50,000 | 约 RM167 |
| 结构框架（15%） | RM125,000 | 约 RM417 |
| 墙身（10%） | RM175,000 | 约 RM583 |
| 屋顶、电线（10%） | RM225,000 | 约 RM750 |
| 批荡（10%） | RM275,000 | 约 RM917 |
| 排污、沟渠、道路（10%） | RM325,000 | 约 RM1,083 |
| 交屋及余款（25%） | RM450,000 | 开始正式月供 |

作为对比，RM450,000、35 年、4% 的正式月供大约是每月 RM1,990。

如果这些阶段平均分布在三年里，在建期间付出的利息大约是 RM20,000。你实际的数字取决于贷款利率、贷款额，以及发展商盖得多快。盖得越快，金额就越早往上跳。

有两点要留意：

- 这笔钱纯粹是利息，并不会减少你欠的 RM450,000。
- 如果你的贷款不到 90%，差额要由你先付给发展商，之后银行才开始放款。

## DIBS 是什么，为什么现在看不到了

2014 年以前，很多项目都以 Developer Interest Bearing Scheme 出售：在建期间的 progressive interest 由发展商代付，买家在完工之前几乎不用付钱。

听起来很慷慨，但成本其实已经算进售价里，也让人很容易用很少的现金去炒房。政府在 2014 年财政预算案中终止了这种做法：发展商不可以推出带有 DIBS 性质的项目，银行也不可以为这类项目提供贷款。

所以现在，progressive interest 是买家自己的成本。发展商还是会提供 rebate 和其他优惠，但那是另一回事。如果有人告诉你“在建期间不用付利息”，请问清楚到底是怎么做到的，并且在文件里看到了才算数。

## 怎样做预算

1. **请银行职员估算。**把房价和贷款额给对方，请他按目前的利率，算出每个阶段的利息。
2. **预留“重叠期”。**如果你现在在租房，就是房租和 progressive interest 一起付，而且金额最高的是拿钥匙前的最后一年。
3. **为利率变动留空间。**大部分房贷是浮动利率，上面的 4% 只是用来说明。
4. **设定自动扣账。**每放一次款，金额就变一次，固定金额的转账会不够。请设定按账单金额扣款的 standing instruction，户口里也要留一点缓冲。
5. **问清楚项目现在盖到哪里。**已经盖到一半的项目，签约后很快就会有较大笔的放款，等待的时间也比较短。
6. **把现金留给收楼。**不要让在建期间的利息，吃掉你原本预留给律师费、装修和搬家的钱。
